
# DARTS Basics

This directory contains initial experiments with Differentiable Architecture Search (DARTS) implemented in PyTorch.

These scripts explore the fundamental concepts of differentiable architecture optimization, including learnable operation selection, softmax relaxation, and gradient-based training.

## Files

- **firstDARTS.py** — Initial implementation exploring basic PyTorch operations and differentiable architecture search.

- **DARTS2.py** — Expanded implementation experimenting with multiple candidate operations and architecture parameters.

- **DARTS3.py** — Further development of DARTS using a directed acyclic graph (DAG), learnable operation weights, and architecture optimization.

## Purpose

These experiments establish the foundation for applying DARTS to automated digital logic circuit discovery, including gate selection, learned connectivity, and hardware-aware optimization.
